<h2><a href="https://www.geeksforgeeks.org/problems/diagonal-morning-assembly0028/1?sortBy=submissions&category%5B%5D=Sorting&page=2&difficulty%5B%5D=1">Sort a Matrix Diagonally</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 14pt;">Given an <strong>n * m</strong> matrix <strong>mat[][]</strong>, rearrange the elements such that:</span></p>
<ul>
<li><span style="font-size: 14pt;">Every diagonal in the lower-left triangle of the matrix is sorted in ascending order.</span></li>
<li><span style="font-size: 14pt;">Every diagonal in the upper-right triangle of the matrix is sorted in descending order.</span></li>
<li><span style="font-size: 14pt;">The main diagonal, starting from the top-left corner, is left unchanged.</span></li>
</ul>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> mat[][] = [[3, 6, 3, 8, 2], [4, 1, 9, 5, 9], [5, 7, 2, 4, 8], [8, 3, 1, 7, 6]]
<strong>Output:</strong> [[3, 9, 8, 9, 2], [1, 1, 6, 5, 8], [3, 4, 2, 6, 3], [8, 5, 7, 7, 4]]
<strong>Explanation:</strong> <br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929911/Web/Other/blobid0_1781863841.png" width="200" height="160"> <img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/929911/Web/Other/blobid1_1781863853.png" width="200" height="160"><br>Each diagonal below the main diagonal is sorted ascending, each diagonal above the main diagonal is sorted descending, and the main diagonal (3, 1, 2, 7) stays unchanged.</span> <span style="font-size: 18px;"><br></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>mat[][] =<strong> </strong>[[5, 8, 1], [9, 2, 6], [3, 7, 4]]<strong><br></strong></span><span style="font-size: 18px;"><strong>Output: </strong>[[5, 8, 1], [7, 2, 6], [3, 9, 4]]<strong><br></strong></span><span style="font-size: 18px;"><strong>Explanation: </strong>The diagonal below the main diagonal (9, 7, 3) sorts ascending to (3, 7, 9), placed back at the same positions. The diagonal above the main diagonal (8, 6) sorts descending to (8, 6), which is already in that order. The main diagonal (5, 2, 4) stays unchanged.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:<br></strong></span><span style="font-size: 18px;">1 &lt;= n, m &lt;= 10^4<br></span><span style="font-size: 18px;">1 &lt;= n × m &lt;= 10^5<br></span><span style="font-size: 18px;">1 &lt;= mat[i][j] &lt;= 10^3</span></p></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>Microsoft</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Sorting</code>&nbsp;<code>Matrix</code>&nbsp;
